# REST API Testing using Postman

## Project Overview
This is a portfolio-style QA API testing project built for demonstrating practical REST API testing skills using Postman.

## Application / API
JSONPlaceholder public REST API: https://jsonplaceholder.typicode.com

## Skills Demonstrated
- REST API testing
- GET, POST, PUT, PATCH and DELETE
- HTTP status-code validation
- Response-body assertions
- Response-time validation
- JSON validation
- Environment variables
- Positive and negative testing
- Collection Runner / regression execution
- Test case documentation

## Project Contents
- `Postman/API_Testing_Collection.json` - import into Postman
- `Postman/QA_Environment.json` - import as environment
- `TestCases/API_Test_Cases.xlsx` - 25 documented test cases
- `Documentation/API_Testing_Report.pdf` - project report
- `Screenshots/` - illustrative portfolio screenshots

## How to Run
1. Install Postman.
2. Import the collection JSON.
3. Import the environment JSON.
4. Select `QA-JSONPlaceholder-Environment`.
5. Open the collection and execute individual requests.
6. Use Collection Runner to execute the full suite.
